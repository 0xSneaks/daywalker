# Daywalker

**The launchpad that walks in daylight.** A Solana launchpad on Meteora's
Dynamic Bonding Curve program with its own published configs: pair anything
with anything, custom taxes, an anti-bundle tax that steps down on a schedule
published before the coin exists, and creator controls — every feature labeled
honestly: **RAILS EXIST / VIA INTEGRATION / VISION**.

Site v1 is informational: no launch or trade functions are wired. Daywalker's
own on-chain configs are not created yet; the site's Configs page shows the
live reference configs its mechanics are verified against, decoded from chain
reads (2026-11-03).

## Run

```bash
npm install
npm run dev   # or: npm run build && npm run start
```

Rules for working in this repo live in `AGENTS.md`.
